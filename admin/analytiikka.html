Vielä yksi asetus

Sivu hakee luvut GoatCounterista, mutta Netlifystä puuttuu GoatCounterin API-avain.

  1. GoatCounterissa: Settings → API → New API key. Anna nimeksi esim. uutisrapsa-admin ja ruksaa vain Read statistics.
  2. Netlifyssä: Site configuration → Environment variables → Add a variable, nimi GOATCOUNTER_TOKEN, arvoksi avain.
  3. Julkaise sivusto uudelleen (Deploys → Trigger deploy), jotta funktio näkee avaimen.
